# 윷 이미지 색상·구조 기준

- `stick-rounded.png`: 둥근 윗면. 진한 호두나무 갈색. 별 표시 없음.
- `stick-flat.png`: 평평한 아랫면. 밝은 나무색. 별 표시 없음.
- `stick-flat-marked.png`: 평평한 아랫면. 밝은 나무색 + 초록색 별.
- `yut-set.png`: 둥근 면이 보이는 윷은 진하게, 평평한 면이 보이는 윷은 밝게 구분.

윷은 반원통 형태이며 별 표시는 빽도 판정용 윷의 평평한 아랫면에만 존재합니다. 게임 판정과 별 윷 인덱스는 변경하지 않습니다.

기존 크기·방향·투명 배경을 유지하여 내장 이미지 생성 도구로 편집했습니다.
편집 요청문: 기존 윷의 형태, 대각선 배치, 크기, 나뭇결과 조명은 유지하고 둥근 윗면만 짙은 호두나무 갈색(#85502d 계열)으로 바꿉니다. 평평한 아랫면은 기존 밝은 나무색을 유지하고, 초록색 별은 평평한 아랫면에만 둡니다. 세트 이미지도 같은 면별 색상을 적용합니다.
