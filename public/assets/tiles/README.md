## 최종 생성 요청문

공통: 조선시대 윷 부동산 게임의 작은 특수칸에 쓸 단일 2D 삽화. 굵고 깨끗한 외곽선, 단순한 민화풍 형태와 무광 색면, 최대 네 가지 색상. 정면 중심 구도, 40px에서도 구분 가능한 실루엣, 투명 배경. 입체 렌더링·볼륨·베벨·반사광·그림자·배경·워터마크 제외. 글자는 복주머니의 福 이외에는 넣지 않음.

대상별 요청: 출발점은 옥색·황토색 대문과 길, 복주머니는 빨강·자주·금색 주머니, 장원급제는 산호색·금색 꽃 모자와 두루마리, 마굿간은 갈색·파랑 말과 마구간, 유배지는 회청색·보라색 섬과 창살 오두막, 놀음판은 보라색 천 위 윷과 엽전, 산적출현은 주황·먹색 복면과 칼, 암행어사는 남색·금색 마패와 술.
